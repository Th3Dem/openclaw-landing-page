> **Статус:** Базовая конфигурация (v1.0 Baseline)  
> **Проект:** OpenClaw / SmartContractum Landing Page & AI Architecture

## 1. Технологический стек (Tech Stack)

### Серверный уровень (Backend):
- **Среда выполнения:** Python 3.12 (Linux / WSL2 Ubuntu)
- **Фреймворк:** FastAPI 0.115+ / Starlette ASGI
- **Сервер приложений:** Uvicorn (с поддержкой автоперезагрузки в dev-режиме)
- **Валидация данных:** Pydantic v2 (строгие схемы запросов `LeadRequest`, `ChatBriefingRequest`)

### Уровень данных и персистентности (Storage):
- **Основное хранилище сессий:** SQLite 3 с журналом WAL (`sessions.db`)
  - Таблицы: `chat_sessions`, `chat_messages`
  - Высокая конкурентность чтения и атомарные транзакции
- **Резервное файловое хранилище (Fallback):**
  - `leads.json` (входящие лиды с формы)
  - `briefs.json` (синтезированные технические задания)

### Искусственный интеллект и LLM (AI Engine):
- **Основной провайдер:** Google Gemini REST API (`v1beta/models/gemini-flash-latest`)
- **Формат генерации:** Структурированный JSON (`responseMimeType: application/json`)
- **Отказоустойчивость:** 
  - Автоматические повторы (2 попытки с задержкой 1.0s при ошибках 503 / 429)
  - Автоматическая нормализация очередности ролей (`user` <-> `model`)
  - Многоуровневый непрерывный семантический fallback-движок без ограничения числа шагов

### Клиентский уровень (Frontend):
- **Шаблонизатор:** Jinja2 с поддержкой i18n (`templates/index.html`)
- **Стили:** Custom CSS3 без внешних тяжелых фреймворков (`static/css/style.css`)
- **Интерактивность:** Vanilla JavaScript ES6+ (`static/js/main.js`)
- **Локализация:** Поддержка RU / EN с автоопределением и сохранением в Cookie

### Почтовая инфраструктура (Notifications):
- **Протокол:** SMTP over SSL (порт 465) / STARTTLS (порт 587)
- **Провайдер:** Yandex Mail SMTP (`smtp.yandex.ru`)
- **Безопасность:** Защита от CRLF-инъекций, экранирование заголовков, HTML-шаблоны с быстрыми ссылками
